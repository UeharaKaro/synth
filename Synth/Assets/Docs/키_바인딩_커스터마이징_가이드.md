## 개요

키 바인딩 커스터마이징 시스템을 통해 각 키 모드별로 원하는 키를 자유롭게 설정할 수 있습니다.

### 주요 기능

#### 기본 기능
- ✅ 각 키 모드별 독립적인 키 설정 (4K, 5K Standard, 5+1K, 6K, 7K, 8K, 10K)
- ✅ 실시간 키 변경 (즉시 적용)
- ✅ 자동 저장 (설정이 영구적으로 보존됨)
- ✅ 기본값 리셋 기능
- ✅ 중복 키 방지
- ✅ ESC로 키 할당 취소

#### 고급 기능 (NEW!)
- 🎯 **테스트 모드**: 키 설정 후 바로 시각적으로 테스트
- 💾 **프리셋 시스템**: 여러 키 설정을 저장하고 빠르게 전환
- 📤 **내보내기/가져오기**: JSON 파일로 키 설정 공유 및 백업
- 📊 **통계 및 히트맵**: 키별 정확도와 사용 빈도 분석

## 키 바인딩 설정 방법

### 1단계: 옵션 메뉴 접속

1. 메인 메뉴에서 **옵션** 선택
2. **키 바인딩** 탭 클릭

### 2단계: 키 모드 선택

1. 상단의 **키 모드 드롭다운**에서 설정할 모드 선택
   - 예: "5+1K" 선택
2. 현재 모드의 키 배치가 화면에 표시됩니다

### 3단계: 키 변경

1. 변경하고 싶은 **트랙 버튼** 클릭
   - 예: "트랙 1: D" 버튼 클릭
2. 버튼이 **노란색**으로 변경됩니다 (대기 중 표시)
3. 원하는 **새 키**를 누릅니다
   - 예: "A" 키를 누름
4. 키가 즉시 변경되고 **자동 저장**됩니다

### 4단계: 취소 또는 완료

- **ESC**: 키 할당을 취소하고 원래대로 돌아갑니다
- **자동 저장**: 변경한 키는 즉시 저장되어 다음에도 유지됩니다

## 5+1K 모드 특수 설정

5+1K 모드는 DJMAX의 5버튼 모드를 모방한 특수 모드입니다.

### 특징

- 트랙 3 (중앙 트랙)은 **F와 J 두 키**로 입력할 수 있습니다
- 양손의 검지로 중앙 트랙을 칠 수 있어 더 편리합니다

### 설정 방법

1. "트랙 3" 버튼을 클릭합니다
2. **첫 번째 키**를 입력합니다 (기본값: F)
   - 예: "F" 누름
3. 시스템이 두 번째 키를 요청합니다
4. **두 번째 키**를 입력합니다 (기본값: J)
   - 예: "J" 누름
5. 두 키가 모두 트랙 3에 할당됩니다

### 표시 예시

```
트랙 1: S
트랙 2: D
트랙 3: F / J  ← 두 키가 동일 트랙에 할당됨
트랙 4: K
트랙 5: L
```

## 고급 기능 사용법

고급 키 바인딩 UI에서 제공하는 편의 기능들을 활용하는 방법입니다.

### 1. 🎯 테스트 모드

키 설정 후 실제 플레이 없이 바로 테스트할 수 있습니다.

#### 사용 방법
1. **"테스트 모드 시작"** 버튼 클릭
2. 화면에 각 트랙을 나타내는 시각적 바가 표시됩니다
3. 설정한 키를 누르면 해당 트랙이 **깜빡이며** 반응합니다
4. 모든 키가 올바르게 작동하는지 확인하세요
5. **"테스트 모드 종료"** 버튼으로 종료

#### 활용 팁
- 새로운 키 배치를 적용한 직후 테스트하세요
- 5+1K 모드에서 F와 J가 모두 중앙 트랙을 트리거하는지 확인
- 키 반응 속도가 만족스러운지 체크

---

### 2. 💾 프리셋 시스템

여러 키 설정을 저장하고 빠르게 전환할 수 있습니다.

#### 프리셋 저장
1. 원하는 키 배치를 먼저 설정합니다
2. **"프리셋 저장"** 섹션으로 이동
3. 프리셋 이름을 입력합니다 (예: "편안한 배치", "넓은 간격")
4. **"저장"** 버튼 클릭
5. 프리셋이 목록에 추가됩니다

#### 프리셋 로드
1. **"프리셋 목록"** 드롭다운 메뉴 클릭
2. 원하는 프리셋 선택
3. **"로드"** 버튼 클릭
4. 키 배치가 즉시 적용됩니다

#### 프리셋 삭제
1. 삭제할 프리셋을 선택
2. **"삭제"** 버튼 클릭
3. 확인 없이 즉시 삭제됩니다 (주의!)

#### 활용 팁
- **상황별 프리셋**: "연습용", "고난이도용", "편안한 플레이용"
- **곡별 프리셋**: "잭 패턴용", "계단 패턴용"
- 각 키 모드마다 독립적인 프리셋을 저장할 수 있습니다

---

### 3. 📤 내보내기/가져오기

키 설정을 파일로 저장하거나 다른 사람과 공유할 수 있습니다.

#### 내보내기 (Export)

**방법 1: JSON 파일로 저장**
1. **"JSON 파일로 내보내기"** 버튼 클릭
2. 파일 저장 위치 선택
3. `keybindings_[모드].json` 파일이 생성됩니다

**방법 2: 클립보드에 복사**
1. **"클립보드에 복사"** 버튼 클릭
2. JSON 데이터가 클립보드에 복사됩니다
3. 메모장이나 채팅으로 붙여넣기 가능

#### 가져오기 (Import)

**방법 1: JSON 파일에서 로드**
1. **"JSON 파일에서 가져오기"** 버튼 클릭
2. 저장된 JSON 파일 선택
3. 키 배치가 자동으로 적용됩니다

**방법 2: 텍스트 입력**
1. JSON 데이터를 복사합니다
2. **"JSON 텍스트 입력"** 필드에 붙여넣기
3. **"가져오기"** 버튼 클릭

#### JSON 파일 형식
```json
{
  "mode": 4,
  "keys": [100, 102, 106, 107]
}
```
- `mode`: 키 모드 (4, 5, -5, 6, 7, 8, 10)
- `keys`: KeyCode 값의 배열

#### 활용 팁
- 친구와 키 설정을 공유하세요
- 여러 PC에서 동일한 설정 사용
- 백업용으로 정기적으로 내보내기
- 커뮤니티에서 인기 있는 설정을 가져오기

## 통계 및 히트맵

플레이 데이터를 분석하여 키별 정확도와 사용 빈도를 시각화합니다.

### 기능 개요

통계 시스템은 게임 플레이 중 모든 키 입력을 기록하고 분석합니다:
- 📈 **키별 정확도**: 각 키의 Perfect/Great/Good/Bad/Miss 비율
- 🔥 **사용 빈도**: 가장 많이 사용하는 키 파악
- ⏱️ **평균 타이밍**: 키별 평균 타이밍 오프셋
- 🗺️ **키보드 히트맵**: QWERTY 레이아웃으로 시각화

### 통계 확인 방법

1. **옵션 메뉴** → **키 바인딩** 탭으로 이동
2. **"통계 보기"** 버튼 클릭
3. 통계 화면이 표시됩니다

### 통계 화면 구성

#### 1. 전체 통계
```
총 입력 횟수: 12,543회
전체 정확도: 94.2%
```

#### 2. 키보드 히트맵
- **QWERTY 레이아웃** 형태로 키보드 표시
- 각 키의 색상으로 정보 전달:
  - **색상 강도**: 사용 빈도 (밝을수록 많이 사용)
  - **색상 종류**:
    - 🟢 **초록색**: 90% 이상 정확도
    - 🟡 **노란색**: 70-90% 정확도
    - 🔴 **빨간색**: 70% 미만 정확도

#### 3. 키별 상세 정보
각 키마다 표시되는 정보:

### 통계 활용 방법

#### 약점 파악
- **낮은 정확도 키** 확인 → 해당 키 집중 연습
- **빨간색 키**가 많다면 전체적인 연습 필요
- **평균 타이밍 오프셋**이 큰 키는 타이밍 조정

#### 키 배치 개선
- 정확도가 낮은 키가 많이 사용된다면 **키 위치 변경** 고려
- 사용 빈도가 낮은 키는 더 먼 위치로 배치해도 무방
- 양손 균형을 확인 (왼손/오른손 사용 빈도)

#### 프리셋 최적화
- 통계를 기반으로 **손 크기 추천** 재조정
- 개인 맞춤 프리셋 생성
- 곡 스타일별로 다른 프리셋 활용

### 통계 관리

#### 통계 초기화
1. **"통계 초기화"** 버튼 클릭
2. 모든 기록이 삭제됩니다 (복구 불가)
3. 새롭게 데이터 수집 시작

#### 통계 내보내기
1. **"통계 내보내기"** 버튼 클릭
2. JSON 파일로 저장됩니다
3. 백업용으로 활용 가능

### 통계 수집 방식

- 게임 플레이 중 **자동으로 수집**됩니다
- 키를 누를 때마다 실시간 기록
- 판정(Perfect/Great/Good/Bad/Miss)과 타이밍 오프셋 저장
- PlayerPrefs에 자동 저장되어 영구 보존

### 활용 팁

1. **정기적으로 확인**: 일주일에 한 번씩 통계 확인
2. **목표 설정**: 전체 정확도 95% 달성 등
3. **약점 집중**: 빨간색 키를 초록색으로 만들기
4. **비교 분석**: 통계를 내보내서 날짜별로 비교
5. **커뮤니티 공유**: 통계 스크린샷을 공유하며 팁 교환

## 문제 해결

### Q: 키를 변경했는데 적용이 안 돼요

**A**: 키는 자동 저장되지만, 게임을 재시작해야 할 수 있습니다. 옵션 메뉴를 나갔다가 다시 들어와서 확인해보세요.

### Q: 실수로 잘못된 키를 할당했어요

**A**: 두 가지 방법이 있습니다:
1. 해당 트랙 버튼을 다시 클릭하고 올바른 키를 입력
2. "기본값으로 리셋" 버튼을 눌러 모든 키를 기본값으로 복원

### Q: 중복된 키를 할당하려고 하면 어떻게 되나요?

**A**: 시스템이 자동으로 차단합니다. "이미 사용 중인 키입니다" 메시지가 표시됩니다.

### Q: ESC 키를 플레이 키로 사용하고 싶어요

**A**: ESC 키는 키 할당 취소 기능을 위해 예약되어 있어 플레이 키로 사용할 수 없습니다.

### Q: 5+1K 모드에서 중앙 트랙 설정이 어려워요

**A**: 순서대로 따라하세요:
1. 트랙 3 버튼 클릭
2. 첫 번째 키 입력 (예: F)
3. 두 번째 키 입력 (예: J)
4. 완료!

### Q: 모든 키 설정을 초기화하고 싶어요

**A**: "모든 키 바인딩 리셋" 버튼을 클릭하면 모든 키 모드가 기본값으로 돌아갑니다.

### Q: 키를 잘못 눌렀을 때 취소하는 방법은?

**A**: **ESC 키**를 누르면 키 할당이 취소되고 원래 키가 유지됩니다.

## 고급 팁

### 편안한 키 배치 찾기

1. **손 크기 고려**: 손이 작으면 좁은 범위의 키를, 크면 넓은 범위의 키를 사용하세요
2. **익숙한 위치**: 다른 리듬 게임 경험이 있다면 비슷한 배치를 사용하세요
3. **연습 모드**: 새 키 배치는 연습 모드에서 먼저 테스트하세요

### 키 모드별 추천 배치

#### 4K 추천
- **초보자**: D, F, J, K (기본값)
- **왼손 중심**: S, D, F, G
- **오른손 중심**: H, J, K, L

#### 5+1K 추천
- **기본**: S, D, F/J, K, L
- **넓은 배치**: A, S, D/K, L, ;
- **좁은 배치**: D, F, G/H, J, K

### 저장 및 백업

- 키 설정은 `PlayerPrefs`에 자동 저장됩니다
- Unity 에디터에서 테스트 시: `Edit > Clear All PlayerPrefs`로 초기화 가능
- 빌드된 게임: 각 플랫폼의 저장 위치에 자동 보존
