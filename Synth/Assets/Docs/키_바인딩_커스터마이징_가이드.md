## 개요

키 바인딩 커스터마이징 시스템을 통해 각 키 모드별로 원하는 키를 자유롭게 설정할 수 있습니다.

### 주요 기능

- ✅ 각 키 모드별 독립적인 키 설정 (4K, 5K Standard, 5+1K, 6K, 7K, 8K, 10K)
- ✅ 실시간 키 변경 (즉시 적용)
- ✅ 자동 저장 (설정이 영구적으로 보존됨)
- ✅ 기본값 리셋 기능
- ✅ 중복 키 방지
- ✅ ESC로 키 할당 취소

## 키 바인딩 설정 방법

### 1단계: 옵션 메뉴 접속

1. 메인 메뉴에서 **옵션** 선택
2. **키 바인딩** 탭 클릭

### 2단계: 키 모드 선택

1. 상단의 **키 모드 드롭다운**에서 설정할 모드 선택
   - 예: "5+1K" 선택
2. 현재 모드의 키 배치가 화면에 표시됩니다

### 3단계: 키 변경

1. 변경하고 싶은 **트랙 버튼** 클릭
   - 예: "트랙 1: D" 버튼 클릭
2. 버튼이 **노란색**으로 변경됩니다 (대기 중 표시)
3. 원하는 **새 키**를 누릅니다
   - 예: "A" 키를 누름
4. 키가 즉시 변경되고 **자동 저장**됩니다

### 4단계: 취소 또는 완료

- **ESC**: 키 할당을 취소하고 원래대로 돌아갑니다
- **자동 저장**: 변경한 키는 즉시 저장되어 다음에도 유지됩니다

## 5+1K 모드 특수 설정

5+1K 모드는 DJMAX의 5버튼 모드를 모방한 특수 모드입니다.

### 특징

- 트랙 3 (중앙 트랙)은 **F와 J 두 키**로 입력할 수 있습니다
- 양손의 검지로 중앙 트랙을 칠 수 있어 더 편리합니다

### 설정 방법

1. "트랙 3" 버튼을 클릭합니다
2. **첫 번째 키**를 입력합니다 (기본값: F)
   - 예: "F" 누름
3. 시스템이 두 번째 키를 요청합니다
4. **두 번째 키**를 입력합니다 (기본값: J)
   - 예: "J" 누름
5. 두 키가 모두 트랙 3에 할당됩니다

### 표시 예시

```
트랙 1: S
트랙 2: D
트랙 3: F / J  ← 두 키가 동일 트랙에 할당됨
트랙 4: K
트랙 5: L
```

## 금지된 키

다음 키들은 시스템 기능을 위해 예약되어 있어 사용할 수 없습니다:

### 사용 불가능한 키

- **ESC**: 키 할당 취소 전용
- **Tab**: 시스템 예약
- **Ctrl** (Left/Right): 시스템 단축키
- **Alt** (Left/Right): 시스템 단축키
- **Command/Windows** (Left/Right): OS 단축키
- **마우스 버튼** (Left/Right/Middle): 마우스 입력

### 사용 가능한 키

- ✅ **Enter / Shift**: 플레이 키로 사용 가능
- ✅ **알파벳 키** (A-Z): 모두 사용 가능
- ✅ **숫자 키** (0-9): 모두 사용 가능
- ✅ **특수 키**: Space, Backspace, ;, ', [, ], \, 등
- ✅ **방향키**: ↑, ↓, ←, →

## 문제 해결

### Q: 키를 변경했는데 적용이 안 돼요

**A**: 키는 자동 저장되지만, 게임을 재시작해야 할 수 있습니다. 옵션 메뉴를 나갔다가 다시 들어와서 확인해보세요.

### Q: 실수로 잘못된 키를 할당했어요

**A**: 두 가지 방법이 있습니다:
1. 해당 트랙 버튼을 다시 클릭하고 올바른 키를 입력
2. "기본값으로 리셋" 버튼을 눌러 모든 키를 기본값으로 복원

### Q: 중복된 키를 할당하려고 하면 어떻게 되나요?

**A**: 시스템이 자동으로 차단합니다. "이미 사용 중인 키입니다" 메시지가 표시됩니다.

### Q: ESC 키를 플레이 키로 사용하고 싶어요

**A**: ESC 키는 키 할당 취소 기능을 위해 예약되어 있어 플레이 키로 사용할 수 없습니다.

### Q: 5+1K 모드에서 중앙 트랙 설정이 어려워요

**A**: 순서대로 따라하세요:
1. 트랙 3 버튼 클릭
2. 첫 번째 키 입력 (예: F)
3. 두 번째 키 입력 (예: J)
4. 완료!

### Q: 모든 키 설정을 초기화하고 싶어요

**A**: "모든 키 바인딩 리셋" 버튼을 클릭하면 모든 키 모드가 기본값으로 돌아갑니다.

### Q: 키를 잘못 눌렀을 때 취소하는 방법은?

**A**: **ESC 키**를 누르면 키 할당이 취소되고 원래 키가 유지됩니다.

## 고급 팁

### 편안한 키 배치 찾기

1. **손 크기 고려**: 손이 작으면 좁은 범위의 키를, 크면 넓은 범위의 키를 사용하세요
2. **익숙한 위치**: 다른 리듬 게임 경험이 있다면 비슷한 배치를 사용하세요
3. **연습 모드**: 새 키 배치는 연습 모드에서 먼저 테스트하세요

### 키 모드별 추천 배치

#### 4K 추천
- **초보자**: D, F, J, K (기본값)
- **왼손 중심**: S, D, F, G
- **오른손 중심**: H, J, K, L

#### 5+1K 추천
- **기본**: S, D, F/J, K, L
- **넓은 배치**: A, S, D/K, L, ;
- **좁은 배치**: D, F, G/H, J, K

### 저장 및 백업

- 키 설정은 `PlayerPrefs`에 자동 저장됩니다
- Unity 에디터에서 테스트 시: `Edit > Clear All PlayerPrefs`로 초기화 가능
- 빌드된 게임: 각 플랫폼의 저장 위치에 자동 보존

## 개발자 참고사항

### 파일 위치

- **KeyBindingUI.cs**: `/Synth/Assets/option/KeyBindingUI.cs`
- **GameSettings.cs**: `/Synth/Assets/option/GameSettings.cs`
- **SettingsManager.cs**: `/Synth/Assets/SettingsManager.cs`
- **InputManager.cs**: `/Synth/Assets/Play/InputManager.cs`

### 데이터 구조

```csharp
// GameSettings.cs
public class KeyBindingEntry
{
    public int lineCount; // 4, 5, -5, 6, 7, 8, 10
    public string keyBindings; // "100,102,106,107" (KeyCode enum)
}
```

### 커스터마이징 방법

1. `GearSettings` 에셋에서 `lineCount` 설정
   - 일반 모드: 양수 (4, 5, 6, 7, 8, 10)
   - 특수 모드: 음수 (-5 = 5+1K)
2. `SettingsManager`가 자동으로 커스텀 키 로드
3. `InputManager`가 키 입력 처리
