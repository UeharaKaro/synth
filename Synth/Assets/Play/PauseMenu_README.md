## 🎮 사용 권장 사항

### PauseMenuUI (기본 버전) 사용 권장:

✅ **프로토타이핑/개발 초기 단계**
- 빠르게 기능 테스트가 필요할 때
- UI 애니메이션보다 게임 로직에 집중할 때

✅ **저사양 디바이스 타겟**
- 모바일 기기
- 저사양 PC
- 성능 최적화가 중요한 경우

✅ **미니멀한 UI 선호**
- 애니메이션 없는 깔끔한 UI
- 즉각적인 반응 선호

✅ **사운드 파일이 없는 경우**
- 효과음 제작 전
- 무음 모드 게임

---

### PauseMenuUIAdvanced (고급 버전) 사용 권장: ⭐

✅ **최종 빌드/출시 버전**
- 풍부한 사용자 경험 제공
- 고급스러운 UI 연출

✅ **고사양 디바이스 타겟**
- PC (데스크톱)
- 콘솔 (PlayStation, Xbox, Switch)
- 고사양 모바일 (선택)

✅ **UI 애니메이션 중시**
- 부드러운 페이드 효과
- 팝업 애니메이션
- 버튼 호버 효과

✅ **사운드 이펙트 사용**
- 일시정지/재개 효과음
- 버튼 클릭 사운드
- 버튼 호버 사운드

6. 애니메이션 설정
7. 사운드 파일 할당 (선택)
8. 테스트

**설정 시간**: 약 15-20분

## 🐛 문제 해결

### 공통 문제:
- ESC 키가 작동하지 않음 → GameManager 확인
- 버튼이 클릭되지 않음 → UI 참조 연결 확인

### 고급 버전 전용:
- 애니메이션이 작동하지 않음 → CanvasGroup 확인
- 사운드가 재생되지 않음 → 오디오 클립 할당 확인

자세한 트러블슈팅은 각 Setup.md 파일의 "트러블슈팅" 섹션 참조
